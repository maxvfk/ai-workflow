# Сторонние MCP-серверы для SolidWorks — сравнение (2026-11-11)

Оценка по README, метаданным и коду на GitHub; установлен и проверен только
`soheil-mp` (`MCP_SOHEIL_SETUP.md`). Машина: SolidWorks 2023 (31.1.0).

| | soheil-mp/solidworks-mcp | hjbaard/SolidWorks-MCP | HarrierPigeon/Solidworks-MCP-Server |
|---|---|---|---|
| Стек | C#/.NET 10, типизированный interop, сборка из исходников против DLL установленного SW | Python, pywin32, ранняя привязка (makepy), STA-поток; `uvx solidworks-mcp` | Python, pywin32, поздняя привязка |
| Состояние на дату | 0.1.0 pre-release, 161 инструмент, 425 живых тестов | 0.19.0, 88 инструментов, 733 теста | последний коммит 2026-08-07 |
| Проверен автором на | SW 2025 SP1.2 | SW 2026 | SW 2025 (требует 2022+) |
| На SW 2023 | собирается после правки двух строк, работает | не проверялся («2020 SP2+ должно работать») | не проверялся |
| Чертежи | полноценные: виды, разрезы, размеры, BOM, GD&T | `make_drawing`: 3 вида + изометрия с размерами модели | нет |
| Безопасность | документы пользователя только чтение; перезапись с согласия и резервной копией; запись только в профиль/%TEMP%; VBA выкл.; модальные диалоги не вешают | нет «выполнить код»; но `save_*`/`close_part` могут сохранять и закрывать | установка `irm … \| iex`; может сам запускать SW |

Вывод: основной — **soheil-mp**; запасной (проще поставить, без сборки) — **hjbaard**,
работать при сохранённых документах пользователя; **HarrierPigeon** — не рекомендуется
(поздняя привязка на этой машине давала ошибки, нет чертежей, давно не обновлялся).

# Правила для агентов при работе с SolidWorks

Обязательны для любого агента и любого способа доступа (MCP-сервер, PowerShell, Python).

## Сохранность работы пользователя

1. **Сначала осмотр.** Получить список открытых документов и признак несохранённых
   изменений (`doc_list` в MCP; `GetSaveFlag` в COM, см. `tools/sw_look_ro.ps1`).
2. **Документы пользователя не сохранять, не закрывать, не перестраивать** без явной
   просьбы. Несохранённые изменения пользователя — его работа.
3. Для осмотра открывать файл **только для чтения** (MCP: `doc_open {readOnly:true}`;
   COM: `OpenDoc6(path, type, 1|2, ...)` — silent + read-only).
4. **Не создавать новый экземпляр SolidWorks** (`Dispatch`/`CreateObject`) — только
   подключаться к запущенному (`GetActiveObject`). Если подключиться не удаётся, разбираться
   с причиной (см. `COM_NOTES.md`), а не запускать второй SolidWorks.
5. Вид пользователя (ориентацию, режим отображения) без нужды не менять; снимки делать
   инструментами, которые восстанавливают вид (MCP `view_screenshot`) или экспортом копии
   (`SaveAs3(png)`).
6. **Правка модели — только по просьбе пользователя.** Перед серией правок — снимок
   (копия файлов модели или `doc_pack`); править по одной операции, после каждой
   проверять результат (объём, габарит, отсутствие новых пересечений, ошибки перестроения).
7. Правка «на месте» (тот же файл) сохраняет внутренние ID и ссылки сборок. «Сохранить как»
   для детали, загруженной в открытую сборку, переключает сборку на новый файл — только
   намеренно.
8. Не держать открытыми десятки окон: 35 открытых деталей роняли SolidWorks.
   Закрывать то, что открыл агент, если пользователь не просил оставить.
9. Перед использованием MCP-сервера попросить пользователя сохранить свою работу: сервер
   работает с живым SolidWorks, при падении SolidWorks теряются несохранённые изменения
   во всех документах.

## Файлы и папки

- Модели в синхронизируемых папках (Яндекс.Диск, OneDrive и т. п.): файлы `~$*` рядом с
  моделью — блокировки открытого SolidWorks, их не трогать и не синхронизировать вручную.
- Чертёж/PDF, открытый у пользователя, не перезаписывается — сохранять рядом с суффиксом
  `_new` и сказать пользователю.
- Не называть свои скрипты именами модулей Python (`inspect.py` и т. п.).

## Данные

- Снимки, геометрия, имена и пути уходят провайдеру модели. Для моделей под NDA или
  экспортным контролем — сначала спросить пользователя.

## Сообщать пользователю

- Что было открыто до работы и в каком состоянии; что агент открыл/закрыл/сохранил.
- Если документ пришлось оставить открытым (например, после открытия он помечен
  изменённым, а закрыть без отбрасывания изменений нельзя) — сказать, какой и как
  закрыть.

# SolidWorks

`solidworks/` — canonical home материалов `ai-workflow` о работе AI-агентов с SolidWorks:
как подключиться к модели, как безопасно читать и править её, какой MCP-сервер ставить и
какие подводные камни уже найдены. Материал вендор-нейтральный: годится для Claude Code,
Claude Desktop (чат), Codex и любого агента, который умеет запускать команды или MCP.

Источник опыта — реальные проекты на рабочей машине пользователя (Windows 11,
SOLIDWORKS Premium 2023 SP1, версия API 31.1.0):

- `SP-LAB-GRANT` (октябрь 2026) — модель макета токовводов: построение и правка деталей,
  сборки, чертежи через COM API из Python (pywin32); подробные приёмы — `tools/README.md`
  того проекта;
- `PIKAPOMP` (ноябрь 2026) — осмотр готовой сборки только на чтение (PowerShell без
  pywin32), габаритная схема для инструкции, установка и проверка MCP-сервера
  `soheil-mp/solidworks-mcp`.

## С чего начать на новой машине

1. Прочитать **[`AGENT_RULES.md`](AGENT_RULES.md)** — короткие обязательные правила для
   любого агента (сохранность документов пользователя, порядок осмотра и правки).
2. Если нужна регулярная работа с моделями (детали, сборки, чертежи, проверки зазоров) —
   поставить MCP-сервер по **[`MCP_SOHEIL_SETUP.md`](MCP_SOHEIL_SETUP.md)**.
3. Если MCP нет или нужна операция, которой нет в сервере, — работать скриптами через COM
   по **[`COM_NOTES.md`](COM_NOTES.md)**; для быстрого осмотра без Python есть
   `tools/*.ps1`.

## Что выбрать: MCP-сервер или свои скрипты

Принципиально новых возможностей MCP-сервер не даёт: внутри тот же COM API. Его ценность —
надёжность и экономия труда:

- 161 готовая и проверенная на живом SolidWorks операция вместо отладки COM-вызовов в
  каждом проекте;
- каждое изменение проверяется (элемент создан, нет ошибок перестроения, объём/геометрия
  изменились), неудачное откатывается с понятной ошибкой;
- документы, открытые пользователем, по умолчанию только читаются и не закрываются;
  перезапись — только с согласия и с резервной копией; системные настройки SolidWorks
  возвращаются даже после сбоя;
- модальное окно SolidWorks не вешает агента: вызов возвращает `DIALOG_BLOCKING`,
  окно можно прочитать и ответить;
- выбор граней/рёбер по геометрии и запросам, а не по экрану;
- дорогие для скриптов вещи одним вызовом: чертежи (виды, разрезы, размеры, BOM, GD&T),
  интерференция и зазоры, сечения, статический расчёт, Pack and Go, выпуск STEP/PDF/DXF;
- снимок вида приходит агенту картинкой, вид пользователя восстанавливается.

Свои скрипты остаются нужны: для разового осмотра (дерево, габариты, снимок), для
операций, которых нет в сервере, и на машине, где сервер не поставлен.

## Правила размещения

- Материал, зависящий именно от SolidWorks, — сюда; общий вывод о работе агентов —
  в подходящую общую область.
- Наблюдение из проекта переносить сюда, когда оно проверено и полезно вне проекта;
  проектные подробности остаются в проекте (ссылаться по Project ID и пути).
- При добавлении файла обновить таблицу выше.

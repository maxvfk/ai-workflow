# Machines

`machines/` — профили рабочих машин пользователя: что установлено, какие MCP-серверы
подключены к каким агентам, где что лежит и какие особенности уже известны. Один файл
на машину, имя — имя компьютера (`$env:COMPUTERNAME`).

## Как агенты узнают о профиле

На каждой машине в глобальных инструкциях агентов стоит одна строка-указатель на файл
этой машины:

- Claude Code — `~/.claude/CLAUDE.md`;
- Codex — `~/.codex/AGENTS.md`.

Сам профиль ведётся только здесь; в глобальных файлах — только указатель.

## Правила

- Перед работой с установленными инструментами (MCP-серверы, SolidWorks, Python и т. п.)
  прочитать профиль своей машины и при сомнении сверить с фактом (команда, конфиг).
- После установки/удаления/перенастройки инструмента или MCP-сервера — обновить профиль
  в том же сеансе работы.
- Без секретов: ни токенов, ни паролей, ни содержимого `.sandbox-secrets` и т. п.
- Общий опыт по инструменту — в его тематическую область (например, `solidworks/`);
  здесь — только состояние конкретной машины и ссылки.

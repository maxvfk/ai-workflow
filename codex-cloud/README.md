- [Новый проект: AGENTS.md + промпт создания среды](NEW_PROJECT_QUICKSTART.md) — краткий стартовый маршрут, минимальные рабочие правила и готовый промпт для чата подготовки.
- [Настройка среды и GitHub workflow](ENVIRONMENT_SETUP.md) — подготовка, Publish/Republish, Bun/PATH, сетевые разрешения, авторизация, холодный запуск и smoke test.

Материал основан на проверке `maxvfk/game-calendar` 30.10.2026. Указанные пути, версии и ограничения описывают **тот конкретный environment**, а не обязательную конфигурацию всех Codex Cloud.

Если появляется общее правило, применимое к разным harnesses, его можно вынести в подходящую общую область отдельным решением.

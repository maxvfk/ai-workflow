# Scenario R1 — Remote Agent

**Status:** Planned  
**Depends on:** [`COMMON.md`](COMMON.md)

Use this scenario when the active agent cannot directly access the user's local filesystem and must retrieve required artifacts through connectors, MCP, or other remote storage interfaces.

This scenario is intentionally not yet specified. It will define discovery, retrieval, bounded reads, materialization into the agent workspace, remote-source provenance, and result publication.
